# 发明名称

一种基于预测资源状态的任务调度方法

# 技术领域

[0001] 本发明涉及计算机任务调度技术领域。

# 背景技术

[0002] 本节仅基于申请人提供的技术问题描述；尚无生产检索支持，不将具体方案表述为公知常识。

# 发明内容

## 要解决的技术问题

[0003] 提供一种在节点负载变化情况下进行任务调度的技术方案。

## 技术方案

[0004] 获取当前及历史资源状态，确定预测资源状态，并结合任务资源需求确定资源匹配度和目标节点。

## 有益效果

[0005] 预测状态参与节点选择，在技术机理上可降低仅依据瞬时状态选择负载上升节点的风险；本申请未主张量化改善。
