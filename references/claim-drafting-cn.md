# Claim drafting — CN

Use consistent terminology and include all necessary technical features in each independent claim. Use two-part form when suitable; use another form when the invention's nature makes that clearer. Dependent claims must refer to earlier claims and add limitations. Multiple dependency must be alternative and must not depend on another multiple dependent claim.

Internal feature annotations must be removed from exported drafts. Primary source: [Implementing Regulations, Rules 22–25](https://www.cnipa.gov.cn/art/2023/12/21/art_98_189197.html).
