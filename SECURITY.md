# Security policy

Report vulnerabilities privately to the repository maintainer rather than opening a public issue containing secrets. Do not attach confidential source code, patent drafts, customer data, private datasets, credentials, or internal URLs.

The scanner uses deny-lists, size limits, and text-file allow-lists, but no automated filter is complete. Review material before sending it to any model or publishing a workspace. Evidence classified `internal-only` or `redaction-required` must not enter exported drafts.
